# ЗИС Барахолка

Доска объявлений по всей Беларуси в духе Куфара: один файл `index.html`, без сервера и сборки.

## Что умеет

- Подача объявлений: категория, заголовок, описание, до 6 фото (сжимаются в браузере), цена / договорная / бесплатно, «возможен торг», состояние, область и город, имя и телефон
- Поиск по тексту, 14 категорий со счётчиками, фильтры: область, город, цена от–до, новое/б/у, только с фото
- Сортировка: новые, дешёвые, дорогие, популярные; вид плиткой или списком
- Карточка объявления: галерея, «Показать телефон» + копирование, просмотры, похожие объявления, страница продавца со всеми его объявлениями, ссылка на объявление (`#ad-<номер>`)
- Публичные вопросы продавцу и ответы продавца
- Избранное, сохранённые поиски, «Вы недавно смотрели»
- Мои объявления: редактирование, «Поднять в поиске» (раз в сутки), «Отметить проданным», удаление
- Жалобы на объявления и раздел модерации для владельца
- Светлая и тёмная тема, адаптив под телефон

## Два режима

- **На claude.ai** (артефакт): общая база, объявления видят все, у кого есть доступ к странице.
- **На GitHub Pages / локально**: демо-режим, объявления сохраняются только в браузере посетителя (localStorage). Для настоящей общей базы на своём хостинге нужен бэкенд (например Firebase или Supabase).
